01  Overview

INSIDE THE CLASSROOM

The classroom is constructed programmatically from geometric primitives — mainly a reusable unit cube, plus a custom 32-segment cylinder mesh for the trash bin. No pre-built 3D models.

02  Features

WHAT IT DEMONSTRATES

3D Transformations

Translation, rotation and scaling applied to the complete scene, combined into a single model matrix with glm::translate, glm::rotate and glm::scale.

Camera System

A custom Camera class with Euler angles (yaw & pitch), keyboard movement, mouse-look, scroll zoom, and perspective projection via glm::lookAt and glm::perspective.

Phong Lighting

Four ceiling point lights with attenuation plus a presentation spotlight with soft inner/outer cutoff — ambient, diffuse and specular components per material.

Animation

The sliding door glides smoothly toward its target using deltaTime, and the ceiling fan spins continuously while switched on — frame-rate independent motion.

Materials

Each object — floor, walls, desks, chairs, blackboard, door — has its own ambient, diffuse, specular and shininess values, so surfaces respond differently to the same lights.

Custom Geometry

A reusable unit cube with normals and indices builds most objects, while a generated cylinder mesh (side faces + caps) forms the trash bin.

04  Run It

BUILD & RUN (WINDOWS)

The project ships as a Visual Studio solution with GLFW, GLAD and GLM included in the Dependencies folder. It requests OpenGL 3.3 Core Profile (#version 330 core shaders).

  1. Download the project ZIP from GitHub and extract it.
  2. Open Classroom.sln in Visual Studio (with C++ development tools installed).
  3. Set the project as the startup project.
  4. Build the solution, then Run — and walk into the classroom.
